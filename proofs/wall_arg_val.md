# WALL-ARG/VAL: the argument/value separation is a scoped theorem

Status: **PROVED** (simplicity argument, §1; exact-computational
verification, §3). Scope declaration in §2. The residue is stated in §4.

*Audit note (2026-10-16): this version corrects two gaps in the draft
proof. (A) The generating set must include the samples themselves
(adjunction form); with rescaled samples alone the statement is
false — counterexample in the audit record (sl(2,R), samples
{H, E+F}, f = i on H only, generates a 3-dimensional algebra that is
neither g nor g_C). (B) The set [N, g] is not in general an ideal
(e.g. in sl(2,R) with N = E, [N, g] = span{E, H}, but [F, H] = 2F is
not in it); the proof below uses the ideal generated by [N, g],
reached by iterated bracketing. Both gaps originated in the chat
proof sketch of 2026-10-16 and are corrected here.*

## 1. The theorem

Let g be a real simple Lie algebra (here g = sl(n,R), n >= 2).
Let {X_a}_{a in A} be a finite sample set from g, Lie-generating g.
Let u be the real Lie algebra generated by the samples together with
their pointwise rescalings:

    { X_a }  union  { f_a(x) X_a : a in A, x in D },

where each f_a : D -> C is a scalar function. Then:

  (i)  if every f_a is real-valued on D, u is a real Lie subalgebra
       of g (in particular dim_R u <= dim_R g);
  (ii) if any f_a takes a nonreal value at any retained sample
       x_0 in D, u = g_C := g (x)_R C as a real Lie algebra, of real
       dimension 2 dim_R g.

In neither case is u a real form of g_C distinct from g itself.
There is no argument-side construction of a second real form.

### Proof

Case (i) is immediate: every generator lies in g, and the samples
are among the generators, so u = g.

Case (ii). Choose a in A and x_0 in D with f_a(x_0) not real. Write
f_a(x_0) = p + qi, q != 0. The generator f_a(x_0) X_a decomposes as

    p X_a  +  q (i X_a),

and X_a itself is a generator (adjunction), so i X_a lies in u:
iN in u with N := X_a != 0 in g.

Since the samples Lie-generate g and are contained in u, g is
contained in u. Now bracket iN against g: for any Y in g,
[iN, Y] = i [N, Y] lies in u, so i V_0 is contained in u, where
V_0 := [N, g] = im(ad_N). V_0 is nonzero: the map
ad : g -> gl(g) has kernel = center(g) = 0, so ad_N != 0 for
N != 0.

Iterate. Set V_{k+1} := V_k + [V_k, g]. Each i V_k is contained in
u: if i V_k is contained in u, then bracketing i V_k against
g (contained in u) gives i [V_k, g] contained in u. Let
W := union_k V_k. Then W is ad_g-invariant, i.e. an ideal of g, and
W contains V_0 != 0. Since g is simple, W = g. Therefore i g is
contained in u, and g + i g = g_C is contained in u. The reverse
containment is immediate (every generator lies in g_C, which is a
real Lie algebra). Hence u = g_C as a real Lie algebra. QED.

*Remark.* The iteration is essential: V_0 alone need not be an
ideal (see the audit note). What simplicity is applied to is the
ideal W generated by V_0, not V_0 itself.

### Remark on semisimple g

If g is only semisimple, the conclusion holds factor by factor:
the ideal W generated by [N, g] is the sum of the simple factors in
which N has a nonzero component, so a nonreal rescaling whose
sample has a nonzero component in a given factor complexifies that
factor; factors in which every nonreally rescaled sample has zero
component remain real. The ladder sl(n,R), n = 3..10, is simple
throughout, so the theorem applies without change.

## 2. Scope: what "argument-side" means here

The class of constructions covered is exactly:

  (a) generators are the samples, or of the form f(x) X with f a
      scalar function on the domain and X a sample from the family;
  (b) the structure is closed under Lie bracket;
  (c) sector projections are admitted, since 1_S(x) is a real scalar
      function.

This is the honest definition of "argument-side": the x-dependence
enters the generator only through a scalar multiplying a fixed
sample matrix. The following operations are NOT in this class, and
the theorem says nothing about them:

  - conjugation X -> M(x) X M(x)^{-1} by a matrix-valued function;
  - coordinate operations on X (e.g. multiplying one matrix entry
    by i, leaving others);
  - the transpose split X = X_s + X_a, which uses the value-space
    structure of X, not the point x.

Each of these uses value-side data; the theorem does not cover them.

## 4. The residue, stated precisely

Wick's rotation is a substitution, not an adjunction. On the
value-side basis {symmetric, antisymmetric}, it acts by

    X_s -> i X_s,   X_a -> X_a,

discarding and replacing the symmetric part. This operation uses the
value-space transpose structure. No pointwise operation on the
operator family realizes it, because:

  - a single sample matrix X(x) mixes its symmetric and antisymmetric
    parts inseparably; and
  - an argument-side operation sees only X(x), never its split.

The transpose split is therefore the precise residue. An exotic
construction that escapes WALL-ARG/VAL must smuggle value-side data
into argument-side costume; the theorem fixes the boundary of the
costume.

## 5. Consequences for the corpus

- wick_via_j.md: the J-route is a special case, with f(x) = -g(x)
  (the pointwise root phase; nonreal exactly on the FW = -1 sectors).
  Covered by the theorem; the FALSIFIED label there remains correct
  and is now a corollary.
- WALL-CPLX: the complex structure J = SG acts through the same
  pointwise rescaling route on samples, so its failure to select a
  compact real form is also covered by the theorem. (J itself, as a
  function-space operator, is not a matrix construction; the
  statement here concerns its use on the generating families.)
- WALL-ARG/VAL is now a scoped theorem rather than a synthesis: the
  statement, the simplicity proof, and the sector table of §3.
